# 🇫🇷 Conjugateur

**Conjugateur** is a personal French verb conjugation practice tool built with React, TypeScript, and Vite. It provides full verb conjugations across all common French tenses for personal study and TCF exam preparation.

This tool is entirely written by GPT-4o for my own use, helping me practice French conjugation with generated conjugation tables and practice prompts. It's not intended for public use.

Supports **je**, **nous**, **ils** by default for practice prompts. More persons and features coming soon.
